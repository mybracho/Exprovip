# Памятка по определению скидки клиента

## Общий принцип

Пустая `Номенклатура` в регистре `СкидкиКонтрагентов` означает общую скидку для всех товаров.

Если для той же комбинации клиента и поставщика есть скидка на конкретную номенклатуру, она имеет приоритет над общей скидкой.

## Порядок поиска скидки

### 1. Особая скидка на месте транзакции

Если такая скидка найдена и для клиента не отключены особые условия, применяется она.

### 2. Скидка клиента по поставщику

Если скидка на месте транзакции не применена, то ищем по поставщику

Сначала ищется скидка по конкретному поставщику.

Приоритет внутри поиска:

1. запись с номенклатурой;
2. запись с пустой номенклатурой.

Если найдена скидка по поставщику и номенклатуре:

ПримененнаяСкидка = На клиенте по поставщику и номенклатуре

Если найдена скидка по поставщику без номенклатуры:

ПримененнаяСкидка = На клиенте по поставщику


### 3. Общая скидка клиента

Если скидка по поставщику не найдена, выполняется поиск общей скидки клиента.

Приоритет внутри поиска:

1. запись с номенклатурой;
2. запись с пустой номенклатурой.

Если найдена общая скидка клиента по номенклатуре:

ПримененнаяСкидка = На клиенте по номенклатуре

Если найдена общая скидка клиента без номенклатуры:

ПримененнаяСкидка = На клиенте

### 4. Скидка группы заправок

Дополнительно определяется скидка для группы заправок.

Группа берется как родитель текущего места транзакции:

Если скидка на конкретной заправке не применена, сравниваются:

- скидка клиента;
- скидка группы заправок.

Применяется меньшая скидка.

Если выбрана скидка группы заправок:

ПримененнаяСкидка = На группе заправок

## Итоговый приоритет

1. Скидка на конкретном месте транзакции.
2. Клиент + поставщик + номенклатура.
3. Клиент + поставщик.
4. Клиент + номенклатура.
5. Клиент.
6. Группа заправок, если она меньше клиентской скидки.
